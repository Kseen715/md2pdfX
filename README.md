md2pdf
======

Сборка PDF из markdown с отрисовкой диаграмм Mermaid.

Нужен для документов, где есть блоки ` ```mermaid `: диаграмму рисует
JavaScript, поэтому pandoc с LaTeX или wkhtmltopdf оставят на её месте
листинг кода. Здесь pandoc собирает HTML, mermaid.js рисует диаграммы в
headless Chrome, и он же печатает результат в PDF.

Требования
----------

- `pandoc` — `sudo apt install pandoc`
- Node.js 18+

Chrome ставится автоматически вместе с `puppeteer` (~180 МБ в
`~/.cache/puppeteer`).

Использование
-------------

```bash
npm ci                       # один раз

node build.js ~/projects/MIOS/ansible/storage/BACKEND-INTEGRATION.md
# → ~/projects/MIOS/ansible/storage/BACKEND-INTEGRATION.pdf
```

Второй аргумент задаёт путь к PDF, если он должен отличаться от исходника:

```bash
node build.js doc.md /tmp/другое-имя.pdf
```

Что получается
--------------

A4, разделы (`##`) с новой страницы, оглавление кликабельное, в нижнем
колонтитуле — заголовок документа и номер страницы. Оформление правится в
`style.css`.

Разметка: о чём стоит помнить
-----------------------------

- Заголовок вида `1. Название` markdown прочитает как **пункт списка**, а не
  как заголовок, — и в PDF, и на GitHub. Писать `## 1. Название`.
- Слишком длинные подписи в диаграммах Mermaid растягивают схему, после чего
  она ужимается под ширину страницы и становится нечитаемой. Длинные подписи
  разбивать через `<br/>`, лишних участников выносить в текст.
