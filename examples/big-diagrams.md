# Большие диаграммы

Диаграмма, которая не влезает в лист, не превращается в нечитаемую мелочь.
md2pdfX по очереди пробует: альбомный лист → другое направление (сверху
вниз ⇄ слева направо) → другую раскладку → и только потом режет её на
куски по высоте листа. Ничего настраивать не нужно.

## Широкая: уходит на альбомный лист

Конвейер сборки из двенадцати шагов в одну строку — на книжном листе он стал
бы мельче 60 %, поэтому получает альбомный лист вместе с этим абзацем и
заголовком.

```mermaid
flowchart LR
    A[Исходники] --> B[Линтер] --> C[Типы] --> D[Юнит-тесты] --> E[Сборка]
    E --> F[Интеграционные<br/>тесты] --> G[Образ Docker] --> H[Сканер<br/>уязвимостей]
    H --> I[Staging] --> J[Нагрузочные<br/>тесты] --> K[Canary 5 %] --> L[Production]
```

## Длинная: режется по листам

Переписка сервисов при оформлении заказа — сорок сообщений. Диаграмма
режется только поперёк и только между сообщениями, так что ни одна стрелка
и подпись не разрываются.

```mermaid
sequenceDiagram
    autonumber
    actor U as Покупатель
    participant W as Сайт
    participant A as API
    participant C as Корзина
    participant S as Склад
    participant P as Платежи
    participant N as Уведомления
    U->>W: Открыть каталог
    W->>A: GET /products
    A-->>W: 200, 48 товаров
    U->>W: Добавить в корзину
    W->>C: POST /cart/items
    C->>S: Проверить остаток
    S-->>C: Есть 12 шт.
    C-->>W: Корзина обновлена
    U->>W: Оформить заказ
    W->>A: POST /orders
    A->>C: Заморозить корзину
    C-->>A: OK
    A->>S: Зарезервировать
    S-->>A: Резерв #7731
    A->>P: Создать платёж
    P-->>A: Ссылка на оплату
    A-->>W: 201, заказ #1042
    W-->>U: Переход к оплате
    U->>P: Ввести карту
    P->>P: 3-D Secure
    P-->>U: Подтвердите код
    U->>P: Код из SMS
    P->>A: Webhook: оплачено
    A->>S: Списать резерв
    S-->>A: Списано
    A->>N: Письмо «Заказ оплачен»
    N-->>U: Email
    A->>S: Передать в сборку
    S->>S: Собрать заказ
    S->>A: Собран
    A->>N: Push «Заказ собран»
    N-->>U: Push
    S->>A: Передан курьеру
    A->>N: SMS с трек-номером
    N-->>U: SMS
    Note over U,N: Прошло два дня
    U->>W: Отзыв ⭐⭐⭐⭐⭐
    W->>A: POST /reviews
    A-->>W: 201
    W-->>U: Спасибо!
```
